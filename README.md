# სასკოლო კალენდრის ავტომატური შემდგენი

ეს არის სტატიკური ვებ-აპი სასკოლო განრიგის ასაწყობად.

## გაშვება

გახსენი ფაილი:

`index.html`

ბრაუზერში დამატებითი სერვერის ან ინსტალაციის გარეშე იმუშავებს.

## რას აკეთებს

- ამატებს კლასებს და ქვეკლასებს, მაგალითად `1ა`, `2ბ`.
- თითოეულ კლასს ანიჭებს სმენას.
- ინახავს სმენების დაწყების დროს, გაკვეთილის ხანგრძლივობას და დასვენებას როგორც გლობალურ პარამეტრებს.
- დასვენება შეიძლება იყოს მუდმივი ან განსხვავებული ყოველი გაკვეთილის შემდეგ, მაგალითად `5, 10, 5, 15`.
- შესაძლებელია მეორე და მესამე სმენის გამორთვა, თუ სკოლას მხოლოდ პირველი სმენა აქვს.
- თითოეულ კლასს ცალკე ანიჭებს დღეში მინიმალურ და მაქსიმალურ გაკვეთილების რაოდენობას.
- თითოეული კლასისთვის თითოეულ საგანს ცალკე ენიჭება, კვირაში რამდენჯერ უნდა ჩატარდეს.
- ამატებს მასწავლებლებს, მათ ერთ ან რამდენიმე საგანს, და თითოეულ საგანთან ცალკე უთითებს რომელ კლასებს ასწავლის.
- აგენერირებს ცხრილს დღეების, გაკვეთილების, საათების, საგნების და მასწავლებლების მიხედვით.
- აგენერირებს რამდენიმე ვარიანტს, რათა მომხმარებელმა აირჩიოს და დატოვოს მისთვის საუკეთესო ცხრილი.
- თუ ცხრილი სრულად ვერ აეწყო, აჩვენებს რომელი გაკვეთილი ვერ განაწილდა.

## შენიშვნა

ამ ვერსიაში თითოეული მითითებული საგანი განაწილდება კვირაში ერთხელ. შემდეგი ბუნებრივი დამატებაა საგნისთვის კვირაში რამდენჯერ უნდა ჩატარდეს, კაბინეტების შეზღუდვები და Excel/PDF ექსპორტი.
